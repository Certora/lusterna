Agents write the proofs.
Lean checks every one.

Lusterna formally verifies Rust programs, especially Solana programs. AI agents infer the intended behavior, translate the code to Lean 4 with Aeneas, and prove it. The Lean kernel checks every proof, and any result that rests on an unproven assumption is rejected.

How it works

Give Lusterna a Rust repository and a short note on what to focus on. Each stage is a separate agent, and the harness checks its output before the next one starts.

  1. 01

    Infer

    Choose the functions and write the properties they should have.

  2. 02

    Translate

    Translate them to Lean 4 with Charon and Aeneas.

  3. 03

    Formalise

    State the properties as Lean theorems.

  4. 04

    Prove

    Prove them, or refute them with a counterexample.

  5. 05

    Report

    Summarise what was proved, as verified by the harness.

Get started

Requires Python 3.10+, Docker, and an Anthropic API key. Results come back as a git branch in your repository.

shell
git clone https://github.com/Certora/lusterna && cd lusterna
python3 -m venv .venv && source .venv/bin/activate
pip install -e .

lusterna build-image                      # one time
export ANTHROPIC_API_KEY=sk-...
lusterna run /path/to/rust-repo design.md
