AI agents can translate Rust to Lean 4 and prove properties about it. But an agent will also report a theorem as proved when its proof relies on a sorry, an unproven axiom, or a weakened statement. Lusterna lets agents do this work and checks every result: Lean checks each proof, Lusterna rejects a proof with a sorry or an added axiom, and the report lists every assumption that a proof depends on. Lusterna works on Rust and Solana programs.

How it works

You provide a Rust workspace and a spec that lists the entrypoints and the properties to verify, or let Lusterna infer both. Lusterna runs five stages on it, each a separate agent, and checks each stage's output before the next one starts. After the last stage, Lusterna writes a report with a verdict for each property.

  1. 01

    Infer

    Infer the entrypoints and the properties from the code and its design document. Optional.

  2. 02

    Pre-translate

    Make the crate build on the host, if it does not already.

  3. 03

    Translate

    Extract a Lean 4 model of the code with Charon and Aeneas.

  4. 04

    Formalize

    State each property as Lean theorems about the model.

  5. 05

    Prove

    Prove each theorem, or refute it with a counterexample.

Get started

Install Lusterna from source. It runs on macOS and Linux, and the build needs a Rust toolchain, opam, Lean 4 and just.

shell
git clone https://github.com/Certora/lusterna && cd lusterna
just setup                                # builds Aeneas and Charon
just install

Write the specification to lusterna.json in the root of your Rust workspace. The entrypoints set the verification scope. Each property is a rule about one or more functions or an invariant of a struct, stated in natural language. With "infer": true, Lusterna infers further entrypoints and properties from the code and its design document.

lusterna.json
{
  "entrypoints": ["crate::vault"],
  "properties": [
    {
      "id": 1,
      "kind": {"Invariant": {"struct": "vault::Vault"}},
      "title": "Shares never exceed the total",
      "natspec": "A vault never has more shares than its total."
    },
    {
      "id": 2,
      "kind": {"Rule": {"fns": ["vault::Vault::withdraw"]}},
      "title": "withdraw burns the requested shares",
      "natspec": "If withdraw returns true, the shares and the total both decrease by the requested amount."
    }
  ],
  "infer": false
}

Run Lusterna in the workspace. It needs the claude CLI, logged in. Lusterna commits the Lean project and the report to the directory lusterna/ of the crate, on the checked out branch.

shell
lusterna run
